의지의 바다 무역 OCR 동선 계산기 v19
======================================

게임 전용 고속·정확 OCR
-----------------------
이번 버전은 일반 문서 OCR이 모든 숫자를 반복해서 읽던 구조를 바꿨습니다.

숫자 인식 순서:
1. 실제 게임 화면에서 학습한 숫자 0~9 템플릿으로 구매가·판매가·재고를 우선 인식
2. 구매 불가의 '-'는 도형으로 별도 판정
3. 템플릿 확신도가 낮은 칸만 RapidOCR/Windows OCR로 정밀 재검사
4. 검토가 필요한 값만 노란색으로 표시

효과:
- 정상 숫자 칸에서는 무거운 텍스트 검출 모델을 실행하지 않음
- 쉼표와 상승·하락 화살표를 숫자에서 분리
- 흰색·파란색·분홍색·노란색 숫자를 같은 글꼴로 정규화해 판독
- 1,071처럼 앞자리 1이 빠지던 문제를 게임 글꼴 자체로 판독
- 18장 일괄 스캔에서도 오류칸만 신경망 OCR을 사용

첨부받은 실제 샘플 2장으로 확인한 숫자:
- 구매가·판매가·재고 숫자 26개: 26개 일치
- 구매 불가/재고 없음 '-' 10칸: 10칸 판정
- 원본의 65%, 80%, 120%, 150% 크기에서도 숫자 26개 일치

이 검증은 제공된 두 샘플에 대한 결과이며, 다른 UI 배율이나 게임 업데이트로
글꼴이 크게 바뀌면 정밀 재검사가 작동하거나 템플릿 갱신이 필요할 수 있습니다.

상품명 정확도 개선
------------------
상품명은 Windows 한국어 OCR을 먼저 한 번 실행합니다.
첫 결과가 약할 때만 확대·선명화·대비 강화 재검사를 추가합니다.

사용자가 표에서 상품명을 수동으로 수정하면 현재 저장된 상품명 목록을 사전처럼 사용해
다음 스캔의 비슷한 오인식을 자동으로 기존 정확한 이름에 맞춥니다.
서로 다른 새 상품을 강제로 예전 상품명으로 바꾸지 않도록 유사도가 충분히 높을 때만 적용합니다.

RTX 3070 보조 OCR
-----------------
기본 게임 숫자 OCR은 작은 셀에서 CPU 템플릿 비교가 더 가볍고 빠르므로 GPU를 사용하지 않습니다.
RTX 3070은 템플릿으로 확실하게 읽지 못한 칸의 신경망 재검사에만 선택적으로 사용합니다.

사용 순서:
1. SETUP.cmd를 먼저 완료
2. GPU_OCR_SETUP.cmd를 1회 실행
3. 프로그램에서 'RTX 보조 OCR(오류칸만)' 체크
4. DIAGNOSE.cmd에서 CUDAExecutionProvider 표시 확인

GPU 설치가 실패하거나 체크를 끄더라도 게임 전용 숫자 OCR과 CPU 정밀 재검사는 정상 작동합니다.
GPU_OCR_SETUP.cmd는 전용 가상환경 안의 ONNX Runtime만 변경합니다.

화면 표시
---------
일괄 OCR 완료 후 다음 수치를 표시합니다.

- 고속 인식: 게임 전용 숫자 OCR로 바로 확정한 칸 수
- 정밀 재검사: 신경망 또는 Windows OCR을 추가 사용한 칸 수
- 검토 필요 칸: 직접 확인할 값 수

자동 균형 계산
--------------
기존의 '내구도 100 가치' 수동 입력을 제거했습니다.

계산 기준의 '자동 균형'을 선택하면 프로그램이 다음 자료로 내구도 가치를 직접 계산합니다.

- 현재 보유 코인
- 현재 상품 구매가·판매가·재고
- 실제 생성된 수익 경로의 턴당 순이익
- 현재 및 종료 내구도
- 이동 1칸의 내구도 소모량
- 수리 타일의 실제 회복량

자동 계산 방식:
1. 현재 가능한 수익 경로들의 턴당 순이익을 구합니다.
2. 극단적인 한 경로의 영향을 줄이기 위해 상위 수익 경로들의 중앙값으로
   이동 1칸 기대수익을 추정합니다.
3. 내구도는 15칸 단위의 미래 무역 회차로 나눕니다.
4. 현재 수익 경로들의 편차를 분석해 미래 회차 할인율도 자동 계산합니다.
5. 가까운 회차에 쓸 내구도는 높게, 먼 회차에 쓸 내구도는 낮게 평가합니다.
6. 최종 코인 + 종료 내구도의 자동 미래가치가 높은 경로를 추천합니다.

따라서 내구도가 적을수록 마지막 100의 가치가 높아지고,
최대 내구도에 가까울수록 같은 100의 가치는 자동으로 낮아집니다.

결과 화면에는 다음 값이 표시됩니다.

- 현재 시장에서 추정한 이동 1칸 기대수익
- 현재 내구도의 마지막 100 추정 가치
- 각 후보 경로의 자동 균형점수
- 각 후보의 종료 내구도 미래가치
- 각 후보 종료 시점의 마지막 100 한계가치

기존 계산 기준도 유지됩니다.

- 이번 회차 코인 최대
- 자동 균형
- 종료 내구도 우선

통행 불가·수리 타일 전용 초기화
--------------------------------
육각 맵 편집기 아래쪽에 다음 버튼을 추가했습니다.

- 통행 불가·수리 타일 초기화

버튼을 누르면 현재 지정된 통행 불가 타일과 수리 타일 개수를 보여주고
초기화 여부를 확인합니다.

초기화되는 항목:
- 통행 불가 타일
- 수리 타일

유지되는 항목:
- 육각 격자 크기
- 북서쪽·북동쪽·서쪽·중앙·동쪽·남쪽 섬 위치
- 이번 판의 실제 섬 이름 배치
- 수리 타일 1개당 회복량
- 이동 1칸당 내구도 소모
- 같은 수리 타일 재방문 설정
- 상품 가격 및 OCR 설정

초기화한 뒤 '저장'을 눌러야 config.json에 반영됩니다.

의지의 바다 무역 OCR 동선 계산기 v16
======================================

게임 화면형 육각 타일 방향 수정
--------------------------------
육각 맵 편집기의 타일 방향을 실제 게임 화면과 동일하게 수정했습니다.

- 꼭짓점이 위·아래를 향하는 세로 육각형(pointy-top)
- 홀수 행이 오른쪽으로 반 칸 이동하는 odd-r 배열
- 화면에 표시되는 좌표는 `열,행`

짝수 행의 4,4 타일 기준 인접 타일:
- 위쪽: 3,3 / 4,3
- 좌우: 3,4 / 5,4
- 아래쪽: 3,5 / 4,5

이 인접 관계를 실제 경로 탐색에도 동일하게 적용하므로,
화면 모양만 바뀐 것이 아니라 장애물 우회 거리와 수리 타일 경유 계산도 함께 수정됩니다.

기존 v15에서 만든 육각 맵은 좌표 데이터는 유지되지만 타일 배열 방향이 바뀌므로,
육각 맵 편집기에서 섬·장애물·수리 타일 위치를 한 번 확인해 주세요.

의지의 바다 무역 OCR 동선 계산기 v15
======================================

이번 버전 핵심
--------------
기존의 섬 사이 거리 숫자만 사용하는 방식에 더해, 실제 육각 타일 맵을 직접 편집하고
다음 요소를 경로 계산에 반영할 수 있습니다.

- 통행 불가 타일
- 장애물 때문에 돌아가는 우회 경로
- 수리 구역 타일
- 수리 타일 1회 방문 시 회복량
- 이동 1칸당 내구도 소모량
- 현재 내구도와 최대 내구도
- 수리 타일을 재방문했을 때 다시 수리할지 여부

EXE 빌드 파일은 포함하지 않았습니다.

실행 순서
---------
1. ZIP 압축을 완전히 풉니다.
2. SETUP.cmd를 최초 1회 실행합니다.
3. 이후에는 RUN.cmd로 실행합니다.
4. 오류가 있으면 DIAGNOSE.cmd를 실행합니다.

육각 맵 설정
------------
메인 화면에서 '육각 맵 편집'을 누릅니다.

편집 도구:
- 바다: 일반 이동 가능 타일
- 통행 불가: 암초·폭풍 등 지나갈 수 없는 타일
- 수리: 방문 시 내구도가 회복되는 타일
- 북서쪽 / 북동쪽 / 서쪽 / 중앙 / 동쪽 / 남쪽: 6개 물리적 섬 위치

왼쪽 클릭:
선택한 도구로 타일을 지정합니다.

오른쪽 클릭:
해당 타일을 일반 바다로 되돌립니다.

수리량:
수리 타일 1개를 방문할 때 회복되는 내구도를 직접 입력합니다.
기본값은 450입니다.

이동 1칸 내구도:
육각 타일 1칸을 이동할 때 소모되는 내구도를 입력합니다.
기본값은 100입니다.

같은 수리 타일 재방문:
- 꺼짐: 같은 계산 경로에서 한 번만 수리
- 켜짐: 다른 이동 구간에서 같은 수리 타일을 다시 지나가면 다시 수리

격자 크기:
행과 열을 4~20 범위에서 바꿀 수 있습니다.
격자를 줄이면 범위를 벗어난 장애물·수리·섬 위치는 제거될 수 있습니다.

섬 이름 배치
------------
육각 맵에서는 물리적 위치만 지정합니다.

예:
- 북서쪽 타일
- 북동쪽 타일
- 서쪽 타일
- 중앙 타일
- 동쪽 타일
- 남쪽 타일

매 판 달라지는 실제 섬 이름은 기존 '이번 판 섬 배치 설정'에서 선택합니다.

예:
북서쪽 = 장인들의 섬
북동쪽 = 목동들의 섬
서쪽 = 조각가들의 섬
중앙 = 어부들의 섬
동쪽 = 감정가들의 섬
남쪽 = 농부들의 섬

경로 계산 방식
--------------
'육각 맵 경로 사용'을 체크하면 고정 거리표 대신 실제 타일을 따라 계산합니다.

프로그램은 다음을 반영합니다.

1. 통행 불가 타일은 통과하지 않음
2. 장애물이 있으면 가능한 우회 경로 탐색
3. 직선 경로와 수리 경유 경로를 모두 후보로 비교
4. 이동할 때마다 내구도 차감
5. 수리 타일에 들어간 직후 수리 적용
6. 최대 내구도를 초과해 수리하지 않음
7. 이동 도중 내구도가 0 아래로 내려가는 경로 제외
8. 다른 섬 타일을 중간에 몰래 통과하지 않음
9. 필수 방문 섬과 방문 금지 섬 조건 적용
10. 중복 섬 방문 허용

예:
농부 → 장인 직선
- 5턴
- 이동 내구도 -500

농부 → 수리 → 수리 → 장인
- 9턴
- 이동 내구도 -900
- 수리 +900
- 순 내구도 변화 0

현재 내구도가 충분하면 직선 경로가 유리할 수 있고,
현재 내구도가 부족하거나 장기 내구도 보존을 중시하면 수리 경로가 선택될 수 있습니다.

계산 기준
---------
메인 화면에서 다음 기준을 선택할 수 있습니다.

1. 이번 회차 코인 최대
현재 회차에서 최종 코인이 가장 높은 순서로 표시합니다.
종료 내구도는 같은 코인일 때 보조 기준으로 사용합니다.

2. 자동 균형
최종 코인과 종료 내구도의 미래 가치를 함께 평가합니다.
사용자가 내구도 가격을 입력하지 않아도 현재 가격표, 보유 코인,
가능 경로의 턴당 순이익과 잔여 내구도 구간으로 자동 산정합니다.

내구도 0~15칸분은 가장 가까운 미래 회차에서 사용할 수 있어 높게 평가하고,
그 이후 15칸 구간들은 먼 미래 몫이므로 현재 시장의 수익 안정성에 따라 단계적으로 할인합니다.
따라서 후반처럼 내구도가 적을 때는 마지막 100의 가치가 커지고,
최대 내구도에 가까울 때는 같은 100의 가치가 작아집니다.

3. 종료 내구도 우선
종료 내구도가 높은 경로를 먼저 표시하고, 같은 내구도라면 코인이 높은 경로를 표시합니다.

결과 표시
---------
각 추천 경로에 다음 내용이 표시됩니다.

- 최종 코인
- 이번 회차 순이익
- 사용 턴
- 시작/종료 내구도
- 총 수리량
- 이동 구간별 턴
- 이동 내구도 소모
- 구간별 수리량
- 구간 종료 내구도
- 실제 타일 좌표 경로
- 섬별 구매·판매 거래

고정 거리표 방식
----------------
'육각 맵 경로 사용'을 끄면 기존 고정 거리표 방식으로 계산합니다.
이 방식은 장애물과 수리 타일을 반영하지 않습니다.
간단한 수동 거리 계산이 필요할 때만 사용합니다.

저장 파일
---------
- config.json: OCR 영역, 섬 배치, 육각 맵, 장애물, 수리량, 계산 기준
- trade_data.json: OCR 가격표와 상품 사용 상태
- startup_error.log: 시작 오류
- runtime_error.log: 실행 중 오류

주의 사항
---------
장애물과 수리 타일은 게임 화면에서 자동 인식하지 않습니다.
현재 버전에서는 사용자가 육각 맵 편집기에서 직접 타일을 지정해야 합니다.
게임에서 장애물 배치가 바뀌면 해당 타일만 수정한 뒤 다시 계산합니다.
