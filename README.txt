의지의 바다 무역 OCR 동선 계산기 v19
======================================

프로그램 소개
-------------
(./1.png)
게임의 무역품 가격과 재고를 OCR로 읽고, 현재 코인·턴·내구도·섬 위치를 기준으로
수익이 높은 구매·판매 동선을 계산하는 프로그램입니다.

주요 기능
---------
- 무역품 스크린샷 일괄 OCR
- 구매가·판매가·재고 자동 인식
- 구매 불가 '-' 자동 판정
- OCR 이상값 노란색 표시
- 필수 방문 섬 및 방문 금지 섬 설정
- 통행 불가 타일 우회 계산
- 수리 타일과 회복량 반영
- 섬 재방문 경로 계산
- 코인 최대·자동 균형·종료 내구도 우선 계산
- 설정과 가격표 자동 저장

설치 및 실행
------------
1. ZIP 파일의 압축을 완전히 풉니다.
2. `SETUP.cmd`를 최초 1회 실행합니다.
3. 설치가 끝나면 `RUN.cmd`로 프로그램을 실행합니다.
4. 오류가 발생하면 `DIAGNOSE.cmd`를 실행합니다.

OCR 사용법
----------
1. `샘플 이미지로 OCR 영역 지정`에서 다음 영역을 지정합니다.
   - 상품명
   - 구매가
   - 판매가
   - 재고량

2. 무역품 스크린샷을 한 번에 선택해 일괄 OCR합니다.

3. 노란색으로 표시된 값은 원본 이미지를 확인한 뒤 직접 수정합니다.

숫자는 게임 전용 템플릿으로 먼저 빠르게 판독하고,
확신도가 낮은 칸만 정밀 OCR로 다시 확인합니다.

육각 맵 사용법
--------------
1. `육각 맵 편집`을 엽니다.
2. 각 타일을 다음 중 하나로 지정합니다.
   - 바다
   - 통행 불가
   - 수리
   - 북서쪽·북동쪽·서쪽·중앙·동쪽·남쪽 섬 위치

3. 수리 타일의 회복량과 이동 1칸당 내구도 소모량을 입력합니다.
4. `이번 판 섬 배치 설정`에서 각 위치의 실제 섬 이름을 선택합니다.
5. `육각 맵 경로 사용`을 체크한 뒤 계산합니다.

통행 불가·수리 타일만 지우려면
`통행 불가·수리 타일 초기화` 버튼을 사용합니다.
섬 위치와 나머지 설정은 유지됩니다.

계산 기준
---------
이번 회차 코인 최대
- 현재 회차에서 최종 코인이 가장 높은 경로를 우선합니다.

자동 균형
- 현재 시장의 수익성, 남은 내구도, 수리 효과를 분석하여
  코인과 내구도를 자동으로 함께 평가합니다.

종료 내구도 우선
- 계산 종료 후 내구도가 가장 많이 남는 경로를 우선합니다.
- 내구도가 같으면 코인이 더 높은 경로를 표시합니다.

GPU 보조 OCR
------------
기본 숫자 OCR은 CPU에서 빠르게 처리됩니다.
GPU는 확신도가 낮은 숫자와 상품명의 정밀 재검사에만 사용됩니다.

NVIDIA 그래픽카드:
1. `GPU_OCR_SETUP.cmd`를 최초 1회 실행합니다.
2. 프로그램에서 `RTX 보조 OCR(오류칸만)`을 체크합니다.
3. `DIAGNOSE.cmd`에서 `CUDAExecutionProvider`가 표시되는지 확인합니다.

현재 GPU 보조 OCR은 NVIDIA CUDA 방식입니다.

- NVIDIA RTX·일부 GTX: GPU 사용 가능
- AMD Radeon: CPU OCR 사용
- Intel Arc·내장 그래픽: CPU OCR 사용
- GPU 설치 실패: 자동으로 CPU OCR 사용

GPU를 사용하지 않아도 프로그램의 기본 OCR과 계산 기능은 정상 작동합니다.

저장 파일
---------
`config.json`
- OCR 영역
- 섬 배치
- 육각 맵
- 통행 불가·수리 타일
- 수리량
- 방문 조건
- 계산 기준

`trade_data.json`
- 상품명
- 구매가·판매가·재고
- 상품 사용 여부
- 원본 이미지 경로

`startup_error.log`
- 프로그램 시작 오류

`runtime_error.log`
- 실행 중 오류

주의사항
--------
- OCR 영역은 게임 해상도나 UI 배율이 바뀌면 다시 지정해야 할 수 있습니다.
- 노란색으로 표시된 값은 계산 전에 원본과 비교해 확인하세요.
- 게임 업데이트로 글꼴이 바뀌면 숫자 템플릿의 정확도가 떨어질 수 있습니다.
- 장애물과 수리 타일은 자동 인식하지 않으므로 직접 지정해야 합니다.
- 게임에서 맵 배치가 바뀌면 섬 배치와 장애물 위치를 다시 확인하세요.
- 프로그램을 옮기거나 업데이트할 때 `config.json`과 `trade_data.json`을 백업하세요.
- 이 프로그램은 비공식 개인 제작 도구이며 게임사와 관련이 없습니다.
